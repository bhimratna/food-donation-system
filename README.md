# 🍱 Food Donation System

A full-stack **Django** web application that connects food donors with NGOs, helping reduce food waste by making the donation process simple, efficient, and accessible.

---

## ✨ Features

- User Authentication
- Food Donation Management
- NGO Dashboard
- Admin Panel
- Image Upload Support
- Responsive Interface

---

## 🛠 Tech Stack

| Technology | Usage |
|------------|-------|
| Python | Backend |
| Django | Web Framework |
| MYSQL | Database |
| HTML/CSS | Frontend |
| Bootstrap | UI |
| JavaScript | Client-side |
| Git | Version Control |

## 🚀 Getting Started

```bash
git clone https://github.com/bhimratna/food-donation-system.git

cd food-donation-system/food_donation

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

Open your browser:

```
http://127.0.0.1:8000/
```
